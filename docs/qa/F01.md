## CODE-01 — erreur JSON mal encodée classée INTERNAL_ERROR

Fichiers concernés : `app/shared/http_errors.py`, fonction `http_error`, et couverture `tests/core/test_transport.py` / `test_http.py`. Priorité normale : divergence concrète du contrat d'erreurs F01, sans fuite observée et sans changement d'architecture requis.

Le contrat `docs/contracts/http.md` exige JSON UTF-8 et corps malformé → **400 INVALID_JSON**. Un corps contenant l'octet `0xff` avec Content-Type application/json produit **400 INTERNAL_ERROR**. FastAPI émet ici une HTTPException 400, qui n'est pas reconnue dans la table `codes` et prend le fallback INTERNAL_ERROR. Le test existant couvre `{` (json_invalid), pas un échec de décodage.

Sonde indépendante exécutée en mémoire par here-string PowerShell vers `.venv/Scripts/python.exe -B -`, avec bytecode désactivé ; code sortie 0. Corps Python exact :

```python
import sys, importlib.util
from fastapi import FastAPI
from fastapi.testclient import TestClient
from app.core.json_transport import JsonTransport
from app.core.request_context import RequestContext
from app.shared.http_errors import install_error_handlers
app=FastAPI()
install_error_handlers(app)
app.add_middleware(JsonTransport)
app.add_middleware(RequestContext)
@app.post('/probe')
def probe(body: dict):
    return body
with TestClient(app, raise_server_exceptions=False) as client:
    r=client.post('/probe',content=bytes([255]),headers={'content-type':'application/json'})
    print('invalid_utf8',r.status_code,r.json()['error']['code'])
print('qa_prefix',sys.prefix)
print('av_present',importlib.util.find_spec('av') is not None)
```

Sortie : `invalid_utf8 400 INTERNAL_ERROR`, préfixe QA, `av_present False`. La sonde constate un résultat et n'est pas présentée comme un test d'acceptation passant.
